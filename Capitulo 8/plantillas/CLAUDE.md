## Claude Code / Claude Cowork

Este archivo existe solo para que Claude Code (y las sesiones de Claude
Cowork, que se ejecutan sobre Claude Code) lean las mismas instrucciones
que ya están en `AGENTS.md`: Claude Code lee `CLAUDE.md`, no `AGENTS.md`
directamente, así que este archivo de una sola línea importa el contenido
del otro con la sintaxis `@AGENTS.md`. No dupliques las reglas de tutoría
aquí: si necesitas una instrucción específica para Claude que no aplique a
otras herramientas, añádela debajo de esta línea, no antes.
